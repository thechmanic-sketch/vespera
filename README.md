# Vespera — Eau de Parfum

Brand website for **Vespera**, the Golden Hour edition. *Wear the last light.*

Static site: HTML, CSS and JavaScript, with GSAP + ScrollTrigger and Lenis (loaded from a CDN).
The page shifts from golden hour to night as you scroll.

## Run locally

```bash
npx serve .
```

Then open http://localhost:5173 (or the address it prints).

## Structure

- `index.html` — page markup
- `css/style.css` — styles
- `js/main.js` — animation and scroll behaviour
- `assets/img/` — optimised WebP images generated in Google Flow (Nano Banana)
